# Project Study

## 分流

- **独立源码问题**：读[源码分析](references/code-analysis.md)，给真实文件/符号证据，不建课程。
- **系统学习**：读[学习流程](references/learning-workflow.md)。有完整路线则续学，否则先规划全部核心单元。
- **写学习记录**：再读[产物结构](references/artifact-templates.md)。

## 硬约束

1. 首次先扫描主要模块，规划覆盖全项目的 U01…Uxx、依赖、能力目标和代表源码；U01 入口须核实，未知细节标待查。
2. 分清「Agent 已查」「已向学员带读」「学员独立掌握」。只有第三者可证明 `completed`；同项目最多一个 `in_progress`。
3. 每轮展示真实代码及一个核实的跳转，只练已教内容，留下一个下一动作。记录相对路径、符号与源码基线；运行结果须真实执行。
