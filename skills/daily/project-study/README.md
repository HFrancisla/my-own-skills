# Project Study

显式调用的代码项目学习 Skill：首次规划**覆盖主要模块的完整学习路线**，随后按 Uxx 带读、验收和续学；也支持单独源码答疑。

## 用法

- 首次：「用 project-study 系统学习这个项目，先规划完整路线，再从 U01 带读。」
- 继续：「用 project-study 从上次保存的进度继续。」
- 答疑：「用 project-study 解释这个模块的主调用链，不建课程。」

## 记录

默认建议在用户授权的 `.project-learning/` 存储：

- `overview.md`：代码与知识地图
- `roadmap.md`：完整路线、Uxx、模块覆盖与验收
- `progress.md`：唯一续学指针
- `sessions/YYYY-MM-DD.md`：真实教学和反馈

未获写入授权时输出完整路线，明确尚未保存。

入口见 [SKILL.md](SKILL.md)；具体流程、产物结构和源码核实规则在 `references/` 中。
