# Artifact Templates — 学习记录格式

仅在用户授权**保存/更新学习资料**时读取。教学阶段、状态判定和复习时机以[学习流程](learning-workflow.md)为准；此处只定义数据位置与写入一致性。

## 保存位置

学习者可选目标项目根目录下 `.project-learning/` 或外部指定目录。默认只读，先确认目录和授权；Skill 包不存可变学习数据。

`.project-learning/` 包含：
- `overview.md`：项目总览及双地图
- `roadmap.md`：单元计划、完成证据、复习安排
- `progress.md`：唯一续学指针
- `sessions/YYYY-MM-DD.md`：按时间追加的学习/复习会话
- `notes/topic.md`：可选的专题知识笔记

## overview.md — 项目与双地图

    # 项目总览
    - 项目路径/来源：
    - 学习目标：
    - 源码基线（branch/commit/dirty 或非 Git）：
    - 核验日期：

    ## 代码地图（职责、模块依赖、已核实的入口和主链）
    ## 知识地图（先修概念、知识依赖、已掌握/待确认/待补及依据）
    ## 未覆盖或待核实的连接

地图是 Agent 的分析资产；仅有地图不能证明学习者看过代码。

## roadmap.md — 稳定的单元计划

    # 学习路线
    - 总体能力目标：
    - 规划依据及调整记录：

    ## U01 · 单元名称
    - 状态：
    - 目标和预计用时：
    - 入口、真实文件/符号和相关测试：
    - 先修概念、依赖单元、学习者知识证据：
    - 2–4 个核心问题：
    - 带读、练习、独立验证动作：
    - 预期完成标准与实际学员证据：
    - 困难/补练及状态原因：
    - 已带读范围（文件/符号，不等于掌握）：
    - 复习状态/上次复习/下次建议日期：
    - 复习结果与证据（保留历史）：

仅单元状态按[学习流程 `4](learning-workflow.md)判定；复习状态单独记录。路线调整保留稳定 Uxx ID 和旧证据；没有复习字段的旧记录表示未知。

## progress.md — 唯一续学指针

    # 当前学习位置
    - 项目与最近核对的源码基线：
    - 更新时间：
    - 当前单元及状态：
    - 当前教学阶段：基础讲解 / 源码示范 / 引导练习 / 独立验证
    - 最近已向学习者带读的文件/符号（不是 Agent 单方侦察）：

    ## 学习者已有的独立掌握证据
    ## 当前疑问或阻塞
    ## 关联 roadmap 单元与最近 session
    ## 近期复习建议（如有）
    ## 下一次第一步：一条符合当前教学阶段的具体动作

保持简短：如果当前是新手源码示范，下一步应为“展示/解释下一小段”，而非让其独立追踪未带读的整链。旧记录没有阶段/带读范围时结合 session 恢复；证据不明从讲解/示范继续。

## sessions/YYYY-MM-DD.md — 实际学习历史

    # YYYY-MM-DD
    ## HH:MM · Uxx · 单元/复习主题
    - 本次目标、源码基线：
    - Agent 已核实、尚未带读的部分（如有）：
    - 实际向学习者展示的源码及示范跳转：
    - 学习者反馈或疑问：
    - 学习者自己的解释与可定位证据（没有则写“待学习者回述”）：
    - 实际实验命令/结果（仅当真正执行）：
    - 状态及依据、补练：
    - 复习结果/下次建议日期（如有）：
    - 下次具体动作：

同一天多次学习向同一文件追加带时间的区块。严格区分 Agent 已核实、已带读和学员已掌握；不要把预计复习写成已经发生。

## notes/topic.md — 可选专题

    # 主题
    - 项目/单元/源码基线：
    ## 核心问题及结论
    ## 文件/符号、机制与设计取舍
    ## 已验证证据与待查假设
    ## 易混淆边界及下次回忆问题

只有复杂调用链、重要机制、经验证的排障经验等值得重复使用的内容才单独建笔记。

## 保存事务与完成标准

1. 核对授权、目标目录和既有文件；增量修改，不覆盖旧完成证据或旧版本的推断。
2. **先写 session 及事实证据 → 更新 roadmap 的状态/复习数据 → 最后更新 progress 指针**。
3. 写后重新读关键字段：当前单元、教学阶段、已带读位置和下一动作一致。日志与日期真实、文件可读、内容不含敏感信息。
4. 未授权写入时返回可复制的进度摘要；旧记录缺新增字段时保持兼容，不补造学习者回答。
