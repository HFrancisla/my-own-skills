# 学习产物结构

默认保存到项目根目录 `.project-learning/`）。

## `overview.md`

项目/学习范围、源码基线；主要模块 → 代表路径 → 职责/依赖 → 证据等级；入口与端到端主链、知识先修图、排除范围和待核实项。

## `roadmap.md`（全局路线）

- 头部：范围、基线、路线版本、日期、必修与可选边界。
- 总表：阶段、顺序、稳定 Uxx ID、能力目标、依赖、代表路径、状态；首次列完全部核心单元。
- 覆盖表：**每个主要模块** → Uxx → 源码位置 → 核实程度/排除原因。
- 单元详情：目标与验收标准、先修知识、代表文件/符号、2–4 个关键问题、带读/实践方式、已教范围、学员独立掌握证据、阻塞与下一步。
- 版本变更：日期、原因、受影响 Uxx；保留已有单元 ID 与完成证据。初始状态均为 `pending`。

## `progress.md`（唯一续学指针）

路线版本、源码基线、更新时间、当前 Uxx/状态、教学阶段（基础讲解/源码示范/引导练习/独立验证）、最近**实际带读**的路径/符号、学员证据与疑问、最近 session、**一个具体下一动作**。尚未带读时 U01 可为 `pending`。

## `sessions/YYYY-MM-DD.md`

同日多次教学按时间追加：Uxx 与基线；Agent 已查但未教的范围；实际展示的代码/跳转；学员回答与反馈；已运行的命令/结果（如有）；状态变化依据与下一动作。没有学员证据就记「无」。

`notes/topic.md` 可选，记录有复用价值的专题分析，不存单元状态。

**保存后核对**：模块覆盖完整；路线版本、指针 Uxx 和最近 session 一致；最多一个 `in_progress`；历史掌握证据可追溯；无敏感信息。
