# 源码分析

用于独立源码答疑，或在模块学习时核实实现。Agent 自行研究不等于已经向学员讲授。

1. **入口**：定位相关文件/符号、输入输出。
2. **主链**：跟踪与问题相关的调用或数据流，直到能观察到结果；核实参数、返回值和副作用。
3. **边界**：检查影响结论的一处分支、异常、状态变化或测试。
4. **结论**：区分文档说法、静态推断、实际运行观察与待验证假设；给出核实方法。

**完成标准**：结论有可定位的相对路径和真实符号；行号（若使用）经过核实，未确认之处明确标「待查」。

独立答疑按「结论 → 源码依据 → 关键边界 → 验证方法」回复。用于教学时只呈现当前需要的一段，再回到当前模块的学习步骤。
