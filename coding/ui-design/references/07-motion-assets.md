# 07 · 动效与素材：只为信息和操作服务

## 动效属于反馈层，不是强制装修

仅在下列情况加入动效：

- 明确因果：点击后按钮/对象发生状态变化；
- 保持空间连续：面板展开、列表重排、页面之间的状态对应；
- 强化时序：加载结束、任务完成、失败提示出现。

不要求固定“三处动效”；每段动效必须说明它帮助了哪个判断。常见 UI 微交互可从短而克制的时长起步（例如约 120–240ms），具体根据品牌、帧率、设备和用户反馈调节。避免无限循环吸睛动画干扰内容。

## 动效验收

- 静态首帧和最后状态均清楚；失败/取消时不会卡在中间状态。
- 交互响应不依赖动画完成；减少动画偏好时依然能理解变化。
- 看不到真实运动画面时，不宣称已验证“手感”或流畅度。
- 动效不影响布局稳定性或重要内容的可达性。

## 素材选择优先级

1. 用户或项目**已授权**的品牌资产与内容；
2. 项目现有组件、图标和插画；
3. 来源清晰、许可允许该用途的免费素材；
4. 自己绘制的基本形状、CSS 图形、图表；
5. **可选**：宿主现有且用户授权的生成能力。

不要求购买素材或调用积分 API，不采集密钥。无法确认许可时不要把网上图片直接当成生产素材。关键图像要服务内容：产品截图应真实、背景图不干扰文字、图表不能牺牲数据可读性。

## 性能预算与替代

优先矢量图标、合适尺寸和压缩后的响应式图片；大型背景视频、WebGL、复杂滚动动画仅在对内容确实有价值且设备性能允许时考虑。没有素材时给出需求清单和可用占位形式，不虚构“已经生成了视觉素材”。
