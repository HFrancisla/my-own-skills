# 学习产物结构

学习产物保存到项目根目录 `.project-learning/`。各文件记录**已发生的研究或学习**，未进入的模块只出现在地图或方向里。

## `overview.md`：项目地图

项目与学习范围、源码基线；主要模块、职责、代表路径及相互关系；简要入口或数据流概览。逐项注明「已核实 / 文档所述 / 待查」，让未知部分保持可见。

## `directions.md`：学习方向

方向名称、学习价值、可能的模块/入口、已知先修关系、待探索问题；可标记一个推荐起点。顺序仅作导航，不是固定课时或完整课程承诺。

## `modules/<slug>.md`：当前模块学习链路

只在学员进入模块时创建，用稳定的模块名命名，包含：

- 学习目标、范围、源码基线、已核实的入口/关键跳转/结果以及待查问题。
- 当前步骤与约 1–3 个近期候选步骤；每步记录源码位置、掌握目标、实际已教范围和下一动作；随学习更新。
- 学员练习、反馈、独立掌握证据与模块状态（`in_progress` / `completed`）。Agent 的调查与讲授记录分别标清。

## `progress.md`：唯一续学指针

当前模块/步骤（首次为「待选择模块」）、教学阶段、最近**实际带读**的路径/符号、源码基线、学员未解决疑问与证据引用、最近会话及唯一下一动作。可链接已经完成的模块。

## `sessions/YYYY-MM-DD.md`：教学事实

同日多轮按时间追加：模块、实际讲授代码/跳转、Agent 已查未教的范围、学员回答或无反馈、执行过的命令及真实结果（如有）、状态变化依据和下一动作。

## 写后核验

文件与路径真实存在（待查项例外）；地图和方向没有详细课程；只有进入过的模块有详细链路；`completed` 有独立掌握证据；最多一个 `in_progress` 焦点；`progress.md` 与最近会话、模块当前步骤一致；无敏感信息。
