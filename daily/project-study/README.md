# Project Study

显式调用的项目源码学习 Skill：先做**项目地图与学习方向**，选定模块后再沿真实源码构建局部学习链路，边学边调整。独立源码问题也可直接答疑。

## 使用

- 「用 project-study 认识这个项目，先给出地图和几个学习方向。」
- 「用 project-study 学习请求处理模块，从实际入口开始带读。」
- 「用 project-study 从上次实际讲到的位置继续。」
- 「用 project-study 解释这条调用链，不创建课程。」

## 产物

默认在项目的 `.project-learning/` 下保存：

- `overview.md`：轻量项目地图。
- `directions.md`：可调整的学习方向。
- `modules/<slug>.md`：开始学习该模块后生成的局部学习链路。
- `progress.md`：当前焦点和下一动作。
- `sessions/YYYY-MM-DD.md`：实际教学、反馈及验收证据。

执行入口见 [SKILL.md](SKILL.md)，详细阶段步骤和产物字段见 `references/`。
